# 换物平台页面交互设计规范

## 1. 首页设计规范

### 1.1 页面布局
- **整体布局**：采用移动端响应式设计，固定头部导航，底部Tab栏
- **顶部区域**：搜索栏 + 消息通知图标
- **主体区域**：轮播图 + 分类导航 + 推荐物品列表
- **底部区域**：Tab导航栏（首页、广场、发布、我的）

### 1.2 页面元素
- **搜索栏**
    - 宽度：100%，高度44px
    - 左侧：放大镜图标
    - 中间：占位符文字"搜索物品、分类等"
    - 右侧：扫描二维码图标
    - 圆角：8px
    - 背景色：#f5f5f5
    - 内边距：0 16px

- **轮播图**
    - 高度：120px
    - 宽度：100%
    - 圆角：8px
    - 轮播指示器：底部居中，白色圆点
    - 自动播放间隔：3秒

- **分类导航**
    - 高度：80px
    - 采用网格布局，4列2行
    - 每个分类项：圆形图标 + 文字标签
    - 图标大小：40px
    - 文字：12px，颜色#333
    - 间距：上下左右各16px

- **推荐物品列表**
    - 采用卡片式布局
    - 卡片高度：120px
    - 左侧：物品图片，宽80px，高80px，圆角8px
    - 右侧：物品信息区域
        - 物品标题：16px字体，加粗
        - 物品描述：14px字体，颜色#666
        - 距离信息：12px字体，颜色#999
        - 价格/积分：14px字体，红色
    - 卡片间距：16px

### 1.3 交互效果
- 搜索栏点击跳转搜索页面
- 轮播图左右滑动切换
- 分类图标点击跳转对应分类页面
- 物品卡片点击跳转详情页
- 下拉刷新列表

## 3. 发布物品页面设计规范

### 3.1 页面布局
- **整体布局**：顶部标题栏 + 主体表单区域
- **顶部区域**：返回按钮 + 标题 + 发布按钮
- **主体区域**：图片上传区 + 基本信息表单 + 折旧程度滑块

### 3.2 页面元素
- **顶部标题栏**
    - 高度：44px
    - 左侧：返回箭头图标
    - 中间：标题"发布物品"
    - 右侧：发布按钮，激活时蓝色，禁用时灰色
    - 背景色：白色
    - 阴影：底部1px灰色阴影

- **图片上传区域**
    - 高度：120px
    - 采用水平滚动布局
    - 每个图片项：宽100px，高100px，圆角8px
    - 第一个：加号图标 + "添加图片"文字，背景色#f5f5f5
    - 已上传图片：显示缩略图 + 删除按钮（右上角×图标）
    - 最多上传5张图片

- **基本信息表单**
    - 每个输入项：高度48px，宽度100%
    - 左侧：标签文字（物品名称、物品类型等）
    - 右侧：输入框或选择器
    - 底部边框：1px solid #eee
    - 内边距：0 16px

- **物品名称输入框**
    - 占位符："请输入物品名称（1-50字符）"
    - 字数统计：右下角显示"0/50"

- **物品类型选择器**
    - 点击弹出下拉选择框
    - 选项：衣服、家具、玩具、电子产品、图书等
    - 已选择项：右侧显示下拉箭头

- **物品描述输入框**
    - 高度：80px
    - 多行输入框
    - 占位符："详细描述物品情况（1-200字符）"
    - 字数统计：右下角显示"0/200"

- **折旧程度滑块**
    - 高度：60px
    - 滑块轨道：浅灰色，高度4px
    - 滑块圆点：直径24px，蓝色
    - 两端标签：全新、很旧
    - 中间数值：显示当前百分比

### 3.3 交互效果
- 图片上传支持拖拽排序
- 输入框实时字数统计
- 滑块拖动时实时显示数值
- 发布按钮在表单完整时激活
- 点击发布显示确认弹窗

## 15. AI生成页面时的关键提示

### 15.1 样式规范
- **色彩方案**：主色调#007AFF，辅助色#ff6b35，背景色#f5f5f5
- **字体规范**：主要使用14-18px，标题加粗，正文常规
- **圆角规范**：按钮8px，卡片8px，输入框8px
- **间距规范**：内边距16px，元素间距8-16px

### 15.2 组件复用
- **按钮组件**：primary、secondary、danger等不同类型
- **输入框组件**：带图标、带清除、带验证等不同样式
- **卡片组件**：物品卡片、用户卡片等不同用途
- **导航组件**：顶部导航、底部Tab、侧边栏等

### 15.3 交互细节
- **触摸反馈**：按钮点击时的视觉反馈
- **加载状态**：数据加载时的loading效果
- **空状态**：无数据时的友好提示
- **错误状态**：操作失败时的错误提示

### 15.4 响应式适配
- **移动端优先**：主要适配手机屏幕
- **横屏适配**：考虑横屏使用场景
- **字体缩放**：适配系统字体大小设置
- **安全区域**：适配刘海屏、挖孔屏等特殊屏幕
